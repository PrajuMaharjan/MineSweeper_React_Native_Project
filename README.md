# MineSweeper

MineSweeper is a cross-platform Minesweeper app built with React Native, Expo, and TypeScript. It features a home screen with navigation to the game, tutorial, settings, and statistics screens, along with a reusable component for rendering the game board.

The project is under active development. The game screen currently displays a covered 9×9 board, while gameplay actions and the tutorial, settings, and statistics screens are not yet implemented.

## Getting started

Install the dependencies:

```bash
npm install
```

Start the Expo development server:

```bash
npx expo start
```

Use the Expo CLI prompts to open the app in Expo Go, an Android or iOS simulator, or a web browser.
